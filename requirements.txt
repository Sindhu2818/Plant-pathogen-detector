# PlantSense — Dependencies
#
# This is a Node.js (npm) project, so there is no Python requirements.txt.
# All dependencies are pinned in `package.json` and locked in
# `package-lock.json`. Install everything with:
#
#     npm install
#

# lucide-react          ^0.400.0    Icon set
